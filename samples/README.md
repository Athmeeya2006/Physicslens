# Sample clips

Short public test clips used in development and `make smoke`. Keep each under 20 s and a few MB.

Recording tips: phone held still on a stand, camera side-on to the motion plane, good light, plain background, 60 fps if possible, a reference object of known size (ruler or A4 sheet) visible in the same plane as the motion.

Planned clips:
- `pendulum.mp4`: weight on a string, small then large swings
- `spring.mp4`: mass bouncing on a spring or rubber band
- `drop_ball.mp4`: ball dropped next to a ruler
- `drop_paper.mp4`: crumpled paper dropped (air drag)

Put anything private in `samples/private/` (gitignored).
